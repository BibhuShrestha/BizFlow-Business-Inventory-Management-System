# Scripts

Utility scripts for the Business Inventory Management System.

| Script | Purpose |
|---|---|
| `seed_roles.py` | Seed the 4 built-in roles (admin, manager, staff, customer). Added in Part 3. |
| `migrate_data.py` | Migrate data from the Flask SQLite/MySQL DB to the new Django DB. Added in Part 17. |

Run scripts from the project root:
    py scripts/<script>.py
